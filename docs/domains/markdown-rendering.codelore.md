# Рендеринг и локализация Markdown-документов

## Состав

- [callouts](../../src/markdown/callouts.codelore.md) — Обеспечивает единообразное отображение уведомлений об устаревших блоках в виде маркдаун-цитаты, используя локализованные шаблоны из localeBundle.
- [locales](../../src/markdown/locales.codelore.md) — Предоставляет локализованный набор строк (заголовки, причины, подсказки) для указанного языка, используя английский как запасной вариант.
- [render-doc](../../src/markdown/render-doc.codelore.md) — Формирует итоговый Markdown-документ, объединяя результаты рендера каждой секции из state.sectionOrder, и возвращает пустую строку при пустом списке секций.

**Зависит от:** [Отпечатки блоков документации](block-fingerprinting.codelore.md#отпечатки-блоков-документации)
**Используется в:** [Фасад сервиса Codelore](codelore-service-facade.codelore.md#фасад-сервиса-codelore) · [Хранилище состояния документации](doc-state-storage.codelore.md#хранилище-состояния-документации) · [Конфигурация проекта](project-config.codelore.md#конфигурация-проекта)

## Зачем это нужно

Подсистема превращает внутреннее состояние документа в готовый Markdown-файл с локализованными заголовками и цитатами об устаревших или непереведённых блоках. Она расставляет локализованные заголовки секций и блоков, группирует устаревшие блоки в цитаты с объяснением причины и даты, а для ещё не переведённых блоков вставляет предупреждение-заглушку. Остальная система получает единый документ, пригодный для публикации, без необходимости разбираться в структуре секций и статусах блоков.

## Что делает

renderDoc перебирает секции в порядке sectionOrder, для каждой вызывает renderSection и склеивает результаты двойным переводом строки. renderSection формирует заголовок секции, получает словарь заголовков блоков через resolveBlockHeadings для заданного языка, затем обходит блоки: свежие выводит с подзаголовком и телом, устаревшие группирует по одинаковой причине и дате в единую цитату с локализованным объяснением — для каждой группы вызывает staleCalloutText, который подставляет причину и дату в шаблон. Блоки без перевода обрабатывает translationPendingCalloutText, вставляя готовое предупреждение. Обе функции цитат разрешают строки через localeBundle, который по языковому ключу достаёт бандл из статического реестра LOCALES, а при отсутствии языка возвращает английский.

## От чего зависит

Подсистема опирается на модуль «Отпечатки блоков документации»: он поставляет данные об изменении кода и устаревании перевода (признаки staleSince и staleReason). Сама подсистема не вычисляет хеши и не синхронизирует переводы — только интерпретирует готовые признаки устаревания, превращая их в видимые пользователю цитаты о неактуальности.

## Кто и как использует

Входная точка renderDoc получает state (секции и их порядок), config и language. Для каждой секции из sectionOrder вызывает renderSection. Та запрашивает у resolveBlockHeadings словарь заголовков блоков для языка — тот дёргает localeBundle, достающий бандл из реестра LOCALES или возвращающий английский. Затем renderSection проходит блоки: свежие сразу попадают в вывод с подзаголовком и телом; устаревшие накапливаются в словаре, сгруппированном по ключу (staleReason, staleSince). Для каждой группы staleCalloutText формирует цитату — определяет локализованную причину через bundle.reasons, заполняет шаблон bundle.callouts.stale значениями reason, since и списком заголовков, оборачивает результат в "> ". Если блок вообще не переведён, translationPendingCalloutText возвращает готовую цитату из bundle.callouts.translationPending. Результаты всех секций renderDoc склеивает двойным переводом строки и добавляет завершающий перевод строки; при пустом sectionOrder возвращает пустую строку.

## Чего не делает

Подсистема не проверяет целостность состояния: отсутствующую секцию молча пропускает, а неизвестный язык заменяет английским без предупреждения. Локализация жёстко привязана к статическому реестру LOCALES, добавить новый язык без изменения реестра невозможно. Заголовки блоков для устаревших групп берутся из resolveBlockHeadings — если ключ блока там не найден, цитата останется без перечисленных заголовков. Подсистема не работает с частично переведёнными блоками: блок либо свежий, либо устаревший, либо не рендерится при rendered: false — промежуточных состояний нет.
