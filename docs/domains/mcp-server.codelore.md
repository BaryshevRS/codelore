# MCP-сервер Codelore

## Состав

- [create-server](../../src/server/create-server.codelore.md) — Точка входа для создания MCP-сервера Codelore с полной настройкой ресурсов, инструментов и навыков.
- [start-stdio-server](../../src/server/start-stdio-server.codelore.md) — Точка входа для подключения MCP-сервера Codelore к stdio-транспорту, делая инструменты и ресурсы документации доступными через stdin/stdout.

**Зависит от:** [Фасад сервиса Codelore](codelore-service-facade.codelore.md#фасад-сервиса-codelore) · [Общие низкоуровневые утилиты](common-utils.codelore.md#общие-низкоуровневые-утилиты) · [Единый формат ошибок](error-handling.codelore.md#единый-формат-ошибок)
**Используется в:** [Точка входа CLI](cli-entrypoint.codelore.md#точка-входа-cli)

## Зачем это нужно

Поднимает MCP-сервер, который подключается к StdioServerTransport и обрабатывает запросы через stdin/stdout, делая ресурсы и инструменты документации Codelore доступными для внешних MCP-клиентов.

## Что делает

Создаёт настроенный McpServer и регистрирует на нём ресурсы и инструменты документации, делегируя все операции фасаду CodeloreService. Если передан projectContext, дополнительно регистрирует ресурс context://project. Подключает готовый сервер к StdioServerTransport, после чего тот начинает принимать и обрабатывать MCP-запросы.

## От чего зависит

Опирается на фасад CodeloreService для всех операций с документацией. Использует общие утилиты для SHA-256-хеширования и нормализации путей, а также единый формат ошибок CodeloreError для сериализации исключений наружу. Не реализует собственных операций с документацией и не поддерживает транспортные протоколы кроме stdio.

## Кто и как использует

Вызов startStdioServer инициирует createCodeloreServer, которая через registerResources и registerTools настраивает обработчики ресурсов и инструментов на McpServer. При наличии projectContext добавляется ресурс context://project. Настроенный сервер подключается к StdioServerTransport. Клиент отправляет MCP-запрос через stdin — транспорт передаёт его зарегистрированному обработчику, тот вызывает соответствующий метод CodeloreService и возвращает результат через stdout.

## Чего не делает

Поддерживает только stdio-транспорт: вызов connect подключает сервер к StdioServerTransport, после чего тот обрабатывает сообщения через stdin/stdout до завершения процесса. Не управляет жизненным циклом после подключения — сервер остаётся активным, и вызывающий код должен сам корректно завершить процесс. Не выполняет операции с документацией самостоятельно, а делегирует их CodeloreService.
