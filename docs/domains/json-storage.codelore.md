## Зачем это нужно

Хранилище сохраняет индексные данные и результаты анализа изменений в JSON-файлы и загружает их обратно. Хранилище изолирует файловый ввод-вывод: само создаёт директории, обрабатывает отсутствие файла, вычисляет пути из конфигурации. Вызывающий код не должен знать пути, создавать директории или обрабатывать ошибки чтения — хранилище делает это само.

## Что делает

Вычисляет пути к файлам из конфигурации (`indexPath`, `changePath`). При записи создаёт все недостающие директории через `fs.mkdir` с `recursive: true`. При чтении перехватывает ошибку `ENOENT` и возвращает `undefined`, не выбрасывая исключение. Хранилище изолирует файловый ввод-вывод: само создаёт директории, обрабатывает отсутствие файла, вычисляет пути из конфигурации.

## От чего зависит

Зависит от встроенного модуля `fs` (Node.js) и объекта конфигурации с полями `indexPath` и `changePath`. Намеренно не занимается семантикой данных: не строит индексы, не анализирует изменения, не проверяет структуру загруженного JSON. Только сериализует переданные объекты в JSON и десериализует прочитанное. Хранилище изолирует файловый ввод-вывод: само создаёт директории, обрабатывает отсутствие файла, вычисляет пути из конфигурации.

## Кто и как использует

Сохранение: получает путь из конфигурации (`indexPath` или `changePath`), создаёт родительские директории через `fs.mkdir` с `recursive: true`, записывает данные как JSON. Загрузка: читает файл по пути; если файл отсутствует (ошибка `ENOENT`), возвращает `undefined`; иначе парсит JSON и возвращает объект. Так хранилище изолирует файловый ввод-вывод: само создаёт директории, обрабатывает отсутствие файла, вычисляет пути из конфигурации.

## Чего не делает

Не проверяет структуру загруженных данных — возвращает результат `JSON.parse` без валидации. При отсутствии файла возвращает `undefined`, и вызывающий код должен сам обработать эту ситуацию. Работает только с путями, заданными в конфигурации (`indexPath`, `changePath`), не поддерживает произвольные расположения. Хранилище изолирует файловый ввод-вывод: само создаёт директории, обрабатывает отсутствие файла, вычисляет пути из конфигурации.
