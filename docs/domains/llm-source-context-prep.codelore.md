# Подготовка исходного контекста для LLM-верификации

## Состав

- [strip-comments](../../src/llm/strip-comments.codelore.md) — Очистка исходного кода от комментариев для передачи в LLM и верификацию.
- [type-context](../../src/llm/type-context.codelore.md) — Сбор объявлений типов, используемых в тексте секций документации, для включения в контекст LLM-верификации.

**Используется в:** [Пайплайн генерации документации файлов](llm-generation-pipeline.codelore.md#пайплайн-генерации-документации-файлов)

## Зачем это нужно

Подсистема готовит для LLM очищенный от комментариев исходный код и контекст объявлений типов, прямо используемых в секциях документации. Результат — компактный синтаксический материал без шума, позволяющий модели сосредоточиться на верификации структуры и типов.

## Что делает

Подсистема удаляет из исходного кода все комментарии, разрешая неоднозначность между оператором деления и началом регулярного выражения на основе предыдущего значимого токена, и нормализует пустые строки (схлопывает три и более перевода строки в два). Затем она находит в файлах объявления типов, на которые прямо ссылаются документируемые секции, отбрасывает типы из внешних пакетов и стандартной библиотеки, удаляет из найденных объявлений комментарии и ограничивает размер каждого объявления и общего результата константами `TYPE_DECL_CAP` и `TYPE_CONTEXT_TOTAL_CAP`.

## От чего зависит

Опирается на компилятор TypeScript: использует `ts.createScanner` для токенизации и разрешение модулей для фильтрации типов. Конфигурационные константы `TYPE_DECL_CAP` и `TYPE_CONTEXT_TOTAL_CAP` регулируют размер выдачи.

## Кто и как использует

Вызывающий код сперва передаёт исходный код в `stripComments` и получает очищенную версию. Затем он вызывает `collectTypeContext`, передавая очищенный код и массив ссылок на типы, извлечённых из документационных секций. `collectTypeContext` для каждой ссылки определяет файл объявления, вырезает фрагмент, отбрасывает внешние и стандартные типы, удаляет комментарии через `stripComments`, проверяет лимиты и накапливает результат. Пара «чистый код + типовой контекст» помещается в промпт LLM.

## Чего не делает

Не обрабатывает JSX (сканер работает в `LanguageVariant.Standard`). Не включает типы из внешних пакетов и стандартной библиотеки. Каждое объявление обрезается до `TYPE_DECL_CAP`, а общий размер результата не превышает `TYPE_CONTEXT_TOTAL_CAP`. Не читает файлы, в которых нет типов, упомянутых в документации. Не заменяет полноценный парсер/лексер — только токенизация через `ts.createScanner`.
