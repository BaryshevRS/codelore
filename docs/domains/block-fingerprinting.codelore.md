## Зачем это нужно

Подсистема вычисляет стабильные отпечатки блоков документации на основе хешей фасетов сущностей, которыми владеет секция. Это позволяет определять, изменилось ли содержимое блока и устарел ли перевод, обновляя зависимые фасеты и скелет только при реальных изменениях, избегая ненужных перерисовок.

## Что делает

Подсистема вычисляет отпечаток блока, хэшируя конкатенацию значений фасетов всех сущностей, которыми владеет секция, через hashFacetAcrossEntities, используя фиксированное отображение BLOCK_FACETS[blockId] для определения набора фасетов. Для определения устаревания перевода она вычисляет SHA-256 хеш обрезанного тела блока. Также она сравнивает сохранённые и текущие отпечатки, выделяя изменённые фасеты, и собирает свидетельства о членстве и кросс-доменных рёбрах для стабильного отпечатка члена домена.

## От чего зависит

Подсистема использует общие низкоуровневые утилиты для детерминированного SHA-256-хеширования строк, что обеспечивает стабильность отпечатков. Она не выполняет файловых операций и не имеет побочных эффектов — все вычисления происходят только над переданными строками, поэтому подсистема безопасна для вызова из любого контекста.

## Кто и как использует

Для определения изменений в блоке подсистема вызывает computeBlockFingerprint, который напрямую хэширует конкатенацию значений фасетов всех владеющих сущностей через hashFacetAcrossEntities, используя фиксированное отображение BLOCK_FACETS[blockId]. Если секция не владеет ни одной сущностью или ни одна из них не присутствует в словаре entities — возвращается undefined. Для определения устаревания перевода translationSourceFingerprint вычисляет SHA-256 хеш обрезанного тела блока. Сравнение сохранённых и текущих отпечатков выполняется diffFacetHashes, который учитывает только фасеты, присутствующие в обоих объектах.

## Чего не делает

Подсистема не обрабатывает случаи, когда секция не владеет ни одной сущностью или ни одна из них не присутствует в словаре entities — в таких ситуациях computeBlockFingerprint возвращает undefined, и сравнение отпечатков невозможно. Также diffFacetHashes учитывает только фасеты, присутствующие в обоих объектах, игнорируя отсутствующие, что может скрыть изменения, если один из отпечатков неполон.
