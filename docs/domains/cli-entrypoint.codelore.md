# Точка входа CLI

## Состав

- [run-cli](../../src/cli/run-cli.codelore.md) — Точка входа CLI, объединяющая парсинг глобальных аргументов, диспетчеризацию команд и обработку ошибок с возвратом кода выхода.

**Зависит от:** [Фасад сервиса Codelore](codelore-service-facade.codelore.md#фасад-сервиса-codelore) · [Визуализация графа файлов](dag-visualization.codelore.md#визуализация-графа-файлов) · [Единый формат ошибок](error-handling.codelore.md#единый-формат-ошибок) · [MCP-сервер Codelore](mcp-server.codelore.md#mcp-сервер-codelore)

## Зачем это нужно

Запускает CLI-инструмент Codelore: разбирает глобальные аргументы, выбирает команду и передаёт управление либо `CodeloreService`, либо `startStdioServer`. При ошибке возвращает код выхода 1 и пишет сообщение в stderr. Сама бизнес-логику не выполняет — только диспетчеризует.

## Что делает

Владеет циклом запуска: парсит глобальные аргументы, диспетчеризует команду, обрабатывает ошибки и форматирует результат в JSON с отступами для stdout. Не валидирует аргументы подкоманд — это делают `assertExpectedArgs` и функции `parse*`.

## От чего зависит

Опирается на `CodeloreService` для выполнения команд, на `startStdioServer` для запуска MCP-режима и на `toCodeloreErrorPayload` или `CodeloreError` для единого формата ошибок. Не занимается бизнес-логикой, не управляет жизненным циклом MCP-сервера и не валидирует аргументы команд — это зоны ответственности других подсистем.

## Кто и как использует

1. Пользователь вызывает CLI с глобальными аргументами. 2. `runCli` парсит аргументы и определяет команду. 3. Если команда — `mcp`, запускает `startStdioServer`; иначе создаёт экземпляр `CodeloreService` и вызывает соответствующий метод. 4. При успехе сериализует результат в JSON и выводит в stdout. 5. При ошибке форматирует ошибку с помощью `toCodeloreErrorPayload`, выводит сообщение в stderr и возвращает код выхода 1.

## Чего не делает

Не выполняет бизнес-логику команд, не управляет MCP-сервером после запуска, не валидирует аргументы подкоманд. Ожидает, что вызывающая сторона использует возвращённый код выхода для завершения процесса.
