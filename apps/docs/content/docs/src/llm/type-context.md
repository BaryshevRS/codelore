## Зачем это нужно

Сбор объявлений типов, используемых в тексте секций документации, для включения в контекст LLM-верификации.

## Что делает

* Не читает файлы, из которых не импортированы типы, упомянутые в секциях.
* Не включает типы из внешних пакетов (isExternal) или стандартной библиотеки (isStdlib).
* Делегирует удаление комментариев из объявлений функции strip-comments.
* Ограничивает каждое объявление до TYPE\_DECL\_CAP и общий размер до TYPE\_CONTEXT\_TOTAL\_CAP.

## На что можно положиться

Никогда не бросает исключения при недоступности файла — запись пропускается через `catch(() => undefined)`. Результат отсортирован по `sourcePath`, затем по `name`.

## От чего зависит

* [`stripComments`](/docs/src/llm/strip-comments#stripcomments) (src/llm/strip-comments.ts) — удаление комментариев из извлечённых объявлений.
* TypeScript compiler API (typescript) — парсинг исходных файлов для поиска объявлений типов.

## Кто и как использует

Вызывается из [`verifyChunkFacts`](/docs/src/llm/file-pipeline#verifychunkfacts) (src/llm/file-pipeline.ts) при `verifyTypeContext: true`. Проходит по каждой секции, находит type-only импорты, упомянутые в тексте секции (через `mentioned`), разрешает их пути относительно файла сущности. Читает файлы по разрешённым путям, извлекает объявления типов, очищает их через [`stripComments`](/docs/src/llm/strip-comments#stripcomments) и возвращает массив, усечённый по размерным ограничениям.

## Чего не делает

* Размерные ограничения: TYPE\_DECL\_CAP (1500) и TYPE\_CONTEXT\_TOTAL\_CAP (6000) — при большом количестве типов часть не помещается в контекст.
* Молча пропускает файлы, которые не удалось прочитать (catch).

## Как менять и что проверять

1. При изменении TYPE\_DECL\_CAP или TYPE\_CONTEXT\_TOTAL\_CAP проверьте, что тесты verifyChunkFacts не ломаются.
2. Если изменить findDeclaration для поддержки export declaration, убедитесь, что возвращаемые объявления по-прежнему чистятся через stripComments.
3. Модификация resolveModulePath может сломать разрешение импортов — проверьте, что все тесты на импорты (test/types/…) проходят.
