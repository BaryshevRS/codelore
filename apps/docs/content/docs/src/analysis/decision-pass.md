## Зачем это нужно

Определяет роль документации для каждой сущности кода на основе метрик, связности классов и обнаружения обёрток.

## Что делает

* Принимает решение о роли документации для каждой сущности, делегируя вычисление роли вспомогательной функции decideEntityRole.
* Не вычисляет метрики, связность или обёртки самостоятельно, а получает их как готовые входные данные.

## На что можно положиться

* Каждая сущность в переданном entities получает ровно одно решение в возвращаемой Map.
* Порядок обработки сущностей детерминирован: сущности сортируются по пути и начальному смещению.

## Кто и как использует

1. Вызывается из populateDocumentationMetadata в [src/indexer/code-indexer.ts](/docs/src/indexer/code-indexer) после вычисления метрик, связности и обнаружения обёрток.
2. Результат используется для определения набора разрешённых блоков документации через determineBlockInclusion.

## calculateWeight

### Зачем это нужно

Вычисляет вес сущности на основе её метрик и, при наличии, метрик приватной части якоря, используемый при принятии решений в анализе.

### Что делает

* Принимает два набора метрик и при необходимости объединяет их для расчёта.
* Применяет логарифмическую формулу для получения веса.

### На что можно положиться

Функция не имеет побочных эффектов и является чистой.
