## Зачем это нужно

Вычисляет метрики связности классов для документационного индекса.

## Что делает

* Не проверяет синтаксическую корректность классов — это ответственность ts-morph.
* Не сохраняет результаты — возвращает Map для обработки вызывающим.
* Не обрабатывает классы без методов — для них поле fieldOverlap равно 0; класс без методов считается не связным, если не задан порог.

## На что можно положиться

* Возвращает запись для каждого класса в records, независимо от наличия методов, со значением cohesive === false для классов без методов.
* Поле fieldOverlap всегда в диапазоне \[0, 1]: 1 для одного метода, 0 для пустого класса; для нескольких методов — доля пар методов с пересечением this-полей.
* Поле graphConnectedness === true для одного метода, false для пустого класса.
* absorbedMethodIds пуст для не cohesive-классов, содержит все entity.id методов класса для cohesive.

## Кто и как использует

Вызывается из `populateDocumentationMetadata` в [`src/indexer/code-indexer.ts`](/docs/src/indexer/code-indexer) после `computeEntityMetrics`. Результат `cohesion` вместе с `metrics` передаётся в `decideDocumentationRoles`, который определяет документационную роль каждой сущности. Если класс cohesive, его методы поглощаются в одну документационную секцию.

## Чего не делает

* Не учитывает статические методы, работающие только с полями: они не принадлежат классу, но технически могут быть поглощены как методы.
* Граф связности строится только по вызовам вида `this.method()` — `super.method()`, вызовы через касты, колбэки, декораторы не учитываются.
* Не обрабатывает геттеры/сеттеры отдельно: они поглощаются как методы, если класс cohesive.

## Как менять и что проверять

1. Если изменился порог связности `classFieldOverlap` — проверить, что секции классов с поглощаемыми методами корректно обновлены в doc-индексе.
2. Если добавилась поддержка `super.method()` или вызовов через колбэки — проверить, что `classContainsAllMethods` не отфильтрует методы, имеющие только внешний вызов, а не через this.
3. Если меняется логика поглощения (absorbedMethodIds) — убедиться, что `populateDocumentationMetadata` в [`src/indexer/code-indexer.ts`](/docs/src/indexer/code-indexer) корректно обрабатывает пустой массив для не cohesive классов (сейчас решения об этом не принимает; ошибка повлияет на doc-роли).
