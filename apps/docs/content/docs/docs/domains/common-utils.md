## Состав

* [hash](/docs/src/utils/hash) — Хеширует строку алгоритмом SHA-256 и возвращает 64-символьное hex-представление.
* [path](/docs/src/utils/path) — Нормализует разделители путей в стиле POSIX для кроссплатформенной совместимости.

## Зачем это нужно

Предоставляет детерминированную идентификацию строк через SHA-256-хеширование и кроссплатформенную нормализацию путей с кодированием для URI — для всех вышележащих модулей проекта. Все функции подсистемы опираются исключительно на встроенные модули Node.js и не обращаются к файловой системе, что делает их безопасными для использования в любых контекстах без побочных эффектов.

## Что делает

Модуль sha256 вычисляет 64-символьный hex-дайджест SHA-256 для произвольной строки без нормализации входа. Путевые утилиты нормализуют разделители к POSIX-слешам, вычисляют относительный путь от корня проекта, проводят быструю эвристическую фильтрацию путей для индексации и кодируют/декодируют идентификаторы в URI-безопасный формат — без добавления схемы или префиксов. Ни одна функция не читает диск и не проверяет существование файлов — все операции чисто строковые, без сайд-эффектов.

## От чего зависит

Подсистема использует только `node:crypto` (хеширование), модуль `path` (resolve) и глобальные функции `encodeURIComponent`/`decodeURIComponent`. Все функции реализованы исключительно на встроенных API Node.js без внешних зависимостей и не обращаются к файловой системе. Нет зависимостей от других модулей проекта или конфигураций.

## Кто и как использует

Утилиты не взаимодействуют друг с другом — каждая вызывается отдельно. Типичная последовательность: строка хешируется `sha256` для идентификации; путь нормализуется `toPosixPath`, приводится к относительному виду `relativeProjectPath`, затем `isProbablyExcluded` помогает решить, нужна ли индексация; для передачи в MCP-сервис `encodeResourceId` кодирует идентификатор, принимающая сторона восстанавливает его через `decodeResourceId`. Все функции реализованы исключительно на встроенных API Node.js без внешних зависимостей и не обращаются к файловой системе.

## Чего не делает

SHA-256 не нормализует вход — разница в регистре или пробелах даёт разные хеши. Путевые утилиты не проверяют существование файлов, не разрешают симлинки и не изменяют регистр; результат `relativeProjectPath` может содержать `..`, если путь вне корня. `isProbablyExcluded` не обрабатывает glob и регулярные выражения, поэтому может пропустить неочевидные пути. `encodeResourceId`/`decodeResourceId` не валидируют идентификаторы и не добавляют URI-префиксы — это делает вызывающий код. Все функции реализованы исключительно на встроенных API Node.js без внешних зависимостей и не обращаются к файловой системе.
