## Состав

* [config](/docs/src/config) — Фабрика конфигурации, объединяющая настройки из `codelore.config.json` с дефолтами.

**Зависит от:** [Рендеринг и локализация Markdown-документов](/docs/docs/domains/markdown-rendering#рендеринг-и-локализация-markdown-документов)
**Используется в:** [Фасад сервиса Codelore](/docs/docs/domains/codelore-service-facade#фасад-сервиса-codelore) · [Пайплайн генерации документации файлов](/docs/docs/domains/llm-generation-pipeline#пайплайн-генерации-документации-файлов)

## Зачем это нужно

Загружает и объединяет настройки проекта из `codelore.config.json` и `.env`-файла, а также выбирает локализованные термины для заданного языка и путей файлов. Система получает единый объект конфигурации и список терминов без необходимости самой разбирать файлы и переменные окружения.

## Что делает

Читает `codelore.config.json`, сливает с дефолтными значениями и возвращает объект конфигурации. Загружает переменные окружения из `.env`-файла в процесс через `process.loadEnvFile`, если файл существует. Фильтрует группы терминов из `docs.terms`: пропускает группу, если её шаблон `match` не соответствует ни одному из переданных путей, затем собирает термины для указанного языка, удаляет дубликаты и пустые строки, сохраняя порядок групп.

## От чего зависит

Подсистема не зависит от других частей Codelore и использует только встроенные механизмы Node.js для чтения файлов и переменных окружения. Сознательно не валидирует схему конфигурации и не разрешает относительные пути — эти обязанности остаются на вызывающем коде.

## Кто и как использует

Загрузка конфигурации начинается с вызова `loadDotEnv`, который проверяет существование `.env`-файла и загружает его переменные в окружение процесса. Затем `loadConfig` читает `codelore.config.json`, объединяет его с дефолтными значениями и возвращает объект — без валидации схемы или разрешения относительных путей. Для получения терминов вызывающая сторона передаёт в `resolveTerms` массив групп терминов из конфигурации, код языка и список путей файлов; функция обходит группы, пропускает те, чей шаблон `match` не совпадает ни с одним путём, собирает термины для языка, удаляет дубликаты и возвращает итоговый список.

## Чего не делает

Не проверяет корректность схемы `codelore.config.json` — синтаксические ошибки JSON приведут к исключению, которое не перехватывается. Не разрешает относительные пути (например, `indexDir`), оставляя их как есть. Каждый вызов `loadConfig` создаёт новый объект конфигурации — подсистема не управляет временем жизни и не кеширует результат. `loadDotEnv` молча пропускает отсутствие `.env`-файла, не сообщая об этом вызывающей стороне. `resolveTerms` может вернуть пустой массив, если ни одна группа терминов не подходит под шаблоны `match` или для языка нет записей. Вызывающий код обязан сам обработать валидацию, разрешение путей и контроль жизненного цикла.
