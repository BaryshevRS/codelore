## Состав

* [stale-detection](/docs/src/service/stale-detection) — Преобразует массив записей о "похороненных" блоках в карту, группируя идентификаторы блоков по идентификатору секции для последующей перезаписи.

**Зависит от:** [Отпечатки блоков документации](/docs/docs/domains/block-fingerprinting#отпечатки-блоков-документации) · [Пайплайн генерации документации файлов](/docs/docs/domains/llm-generation-pipeline#пайплайн-генерации-документации-файлов) · [Общие вспомогательные функции сервиса](/docs/docs/domains/service-helpers#общие-вспомогательные-функции-сервиса)
**Используется в:** [Фасад сервиса Codelore](/docs/docs/domains/codelore-service-facade#фасад-сервиса-codelore)

## Зачем это нужно

Выявляет устаревшие блоки документации: сравнивает сохранённые отпечатки с актуальным кодом и документацией зависимостей, находит блоки с удалёнными сущностями, блоки на неверном языке и ранее «похороненные». Объединяет результаты разных проверок в единый список без дубликатов и готовит контекст для планировщика перезаписи.

## Что делает

Проверяет каждый блок документации: вычисляет текущий отпечаток через подсистему отпечатков и сравнивает с сохранённым, фиксируя изменившиеся фасеты (staleBlockInfoFor). Для секций, все принадлежащие сущности которых удалены, помечает все блоки как устаревшие с причиной owned\_entity\_deleted (deletedOwnedEntityBlocks). Анализирует отпечатки документации зависимостей и отбирает непропагирующие блоки, документация зависимостей которых изменилась (collectDepDocStaleBlocks). Отбирает блоки, чей язык отличается от канонического, если тот задан (collectLanguageStaleBlocks). Находит блоки, уже отмеченные как «похороненные», по наличию staleSince, не обращаясь к коду (collectTombstonedBlocks). На основе похороненных записей формирует карту целевых разделов для перезаписи (targetBlocksFromTombstones), убирая неизвестные и дублирующиеся идентификаторы. Для каждого устаревшего блока собирает RewritContextBundle с текущим текстом и сводками сущностей из индекса (buildRewriteContextBundle). Формирует итоговый результат с метриками и планом перезаписи (refreshStaleResult).

## От чего зависит

Зависит от подсистемы «Отпечатки блоков документации» для получения актуальных отпечатков фасетов и документации зависимостей; сама отпечатки не вычисляет. Использует «Общие вспомогательные функции сервиса» для проверки идентификаторов блоков (isKnownBlockId) и других утилит. Оперирует проектным индексом (index.docs.sections, index.code.entities), который передаётся извне. Не выполняет перезапись блоков, не изменяет состояние индекса и не управляет хранилищем — только возвращает данные и контекст.

## Кто и как использует

Основной сценарий начинается с вызова collectStaleBlocks: для каждой секции, имеющей принадлежащие сущности, staleBlockInfoFor запрашивает текущий отпечаток блока и сравнивает с сохранённым; при расхождении формируется StaleBlockInfo с diff-фасетами. Если секция потеряла все сущности, deletedOwnedEntityBlocks перебирает её блоки и для каждого создаёт запись с drift: owned\_entity\_deleted. Параллельно collectDepDocStaleBlocks проходит по секциям с depDocsFingerprint, сравнивает отпечатки зависимостей и включает только непропагирующие блоки, не пустые и ещё не устаревшие. collectLanguageStaleBlocks проверяет блоки с заданным canonicalLanguage и добавляет записи с фасетом language. collectTombstonedBlocks собирает блоки с установленным staleSince, не требуя вычисления отпечатков. Все полученные массивы устаревших блоков сливаются через mergeStaleBlocks: дедупликация по sectionId + \0 + blockId, при повторах объединяются changedFacets. Далее buildRewriteContextBundle для каждой записи извлекает из индекса секцию, блок и сводки сущностей (summarizeCodeEntity), формируя RewritContextBundle с текущим текстом, принадлежащими сущностями и причинами. refreshStaleResult упаковывает итог: вычисляет метрики stale, tombstoned и, при режиме tombstone, appliedTombstones, а также включает план перезаписи, если он был передан.

## Чего не делает

Не проверяет пропагирующие блоки на устаревание из-за документации зависимостей (collectDepDocStaleBlocks). Пропускает блоки с неизвестным идентификатором во всех этапах: addTargetBlock, staleBlockInfoFor, tombstonedBlockInfoFor и collectLanguageStaleBlocks. Игнорирует блоки с пустым телом. Блоки, уже отмеченные как устаревшие (staleSince), не попадают в свежую проверку кодом, но собираются отдельно как «похороненные». Секции без depDocsFingerprint не участвуют в проверке документации зависимостей. Если canonicalLanguage не задан, collectLanguageStaleBlocks возвращает пустой массив. Подсистема не выполняет перезапись — только формирует RewritContextBundle. Не модифицирует хранилище или индекс, не управляет потоком обновления.
