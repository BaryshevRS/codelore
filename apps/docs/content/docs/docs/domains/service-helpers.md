## Состав

* [helpers](/docs/src/service/helpers) — Проверяет пересечение двух отрезков на числовой оси.

**Зависит от:** [Единый формат ошибок](/docs/docs/domains/error-handling#единый-формат-ошибок)
**Используется в:** [Фасад сервиса Codelore](/docs/docs/domains/codelore-service-facade#фасад-сервиса-codelore) · [Согласование и валидация состояния документации](/docs/docs/domains/doc-state-consistency#согласование-и-валидация-состояния-документации) · [Подготовка первичной документации](/docs/docs/domains/initial-docs-preparation#подготовка-первичной-документации) · [Применение перезаписей секций](/docs/docs/domains/section-rewrite-application#применение-перезаписей-секций) · [Обнаружение устаревших блоков документации](/docs/docs/domains/stale-blocks-detection#обнаружение-устаревших-блоков-документации)

## Зачем это нужно

Предоставляет набор чистых утилит для типовых операций сервисного слоя: проверка пересечения диапазонов, дедупликация и сортировка массивов строк и сущностей, поиск первого дубликата, свёртка полных сущностей и секций документации в краткие представления, группировка по ключу, проверка идентификаторов блоков и нормализация ошибок. Остальной код сервиса использует эти функции, чтобы избежать дублирования и обеспечить единообразие обработки данных.

## Что делает

Владеет реализацией перечисленных утилит. Каждая функция выполняет одну атомарную операцию: rangesOverlap определяет пересечение отрезков, uniqueSorted и uniqueEntities удаляют дубликаты и сортируют результат, firstDuplicate находит первое повторение, summarizeCodeEntity и summarizeDocSection строят компактные представления, groupBy собирает элементы в Map по строковому ключу, isKnownBlockId проверяет принадлежность строки к известным идентификаторам блоков, describeError нормализует любое значение ошибки в объект с сообщением и опциональным кодом. Все функции чистые: не изменяют входные данные и не имеют побочных эффектов.

## От чего зависит

Опирается на подсистему «Единый формат ошибок»: функция describeError распознаёт экземпляры CodeloreError и извлекает из них код ошибки, сохраняя единообразие сообщений об ошибках. describeError — единственная функция, которая взаимодействует с внешней подсистемой; все остальные утилиты самодостаточны. Сама подсистема не определяет форматы ошибок и не занимается их логированием или передачей.

## Кто и как использует

Утилиты не образуют единого сквозного процесса, а комбинируются вызывающим кодом по мере необходимости. Типичная цепочка: после получения списка сущностей их дедуплицируют через uniqueEntities, затем каждую сворачивают через summarizeCodeEntity и группируют по нужному признаку с помощью groupBy. При валидации конфигурации проверяют идентификаторы блоков через isKnownBlockId, а возникшие исключения нормализуют через describeError перед отправкой клиенту.

## Чего не делает

Не проверяет корректность входных данных: rangesOverlap не требует упорядоченных концов отрезка, groupBy полагается на строковый ключ и не обрабатывает null/undefined. Работает только с синхронными операциями. Не управляет состоянием и не взаимодействует с внешними хранилищами. Список известных идентификаторов блоков в isKnownBlockId фиксирован на этапе компиляции.
