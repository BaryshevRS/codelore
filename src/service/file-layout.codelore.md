# planFileLayout

## Зачем это нужно

Преобразует список сущностей кода в структурированный план секций документации для одного файла.

## Что делает

- Сортирует сущности по возрастанию `startOffset`.
- Для всех остальных сущностей назначает заголовок первого уровня с полным именем.
- Не генерирует содержимое документации и не сохраняет результат.

## На что можно положиться

- Возвращённые `PlannedSection` расположены в порядке возрастания `startOffset` исходных сущностей.
- Для метода класса заголовком является только имя метода (без префикса класса), глубина 2.
- Для всех прочих сущностей заголовком является полное имя сущности, глубина 1.
- Результат не сохраняется и не сериализуется — только возвращается.

## Кто и как использует

- Вызывается из [`CodeloreService.prepareInitialDocs`](codelore-service.codelore.md#prepareinitialdocs) для каждой группы сущностей, сгруппированных по исходному файлу.
- Результат используется для заполнения `DocState.sectionOrder` и создания свежих `DocStateSection` для каждой запланированной сущности.
- Если сущность уже существовала в состоянии, её блоки не перезаписываются — сохраняются через `withPreservedBlockBodies`.

## Чего не делает

- Не обрабатывает сущности с именами, содержащими точку, если они не являются методами классов (например, вложенные сущности).
- Определение владеющего класса основывается только на именах классов из того же набора `entities` — если метод относится к классу из другого файла, он не будет распознан.
- Не поддерживает пользовательские заголовки или переопределение глубины.

## Как менять и что проверять

- Сортировка по `startOffset`: секции располагаются в порядке возрастания начального смещения. Конструкция: `[...entities].sort((left, right) => left.range.startOffset - right.range.startOffset)`. Тестовый файл: не указан.
- Заголовок метода класса: для методов класса заголовком является только имя метода (без префикса класса). Конструкция: `entity.name.slice(lastDot + 1)` внутри условия `entity.type === "method" && hasOwningClassInBatch(entity, classNames)`. Тестовый файл: не указан.
