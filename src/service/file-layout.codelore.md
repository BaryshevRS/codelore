# planFileLayout

```ts
planFileLayout(entities: CodeEntity[]): PlannedSection[]
```

## Зачем это нужно

Преобразует список сущностей кода в структурированный план секций документации для одного файла.

## Что делает

- Сортирует сущности по возрастанию `startOffset`.
- Для всех остальных сущностей назначает заголовок первого уровня с полным именем.
- Не генерирует содержимое документации и не сохраняет результат.

## На что можно положиться

- При пустом входном массиве возвращает пустой массив.
- Каждая сущность из входного массива порождает ровно один PlannedSection, даже если сущности дублируются.
- Возвращённый массив отсортирован по возрастанию `startOffset` сущностей.
- Входной массив не изменяется — функция создаёт копию и возвращает новый массив.
- Для файловых сущностей (`type === "file"`) глубина секции — 1, заголовок — последний компонент имени после `/` (или полное имя, если `/` отсутствует).
- Для методов, чей класс присутствует в том же наборе сущностей, глубина — 2, заголовок — только имя метода (часть после последней точки).
- Для всех остальных сущностей глубина — 1, заголовок — полное имя сущности.

## Кто и как использует

Принимает массив сущностей, сортирует их по `startOffset` и для каждой возвращает `PlannedSection` с заголовком, основанным на типе сущности и наличии владеющего класса.

## Чего не делает

- Сущности с точкой в имени, не являющиеся методами (например, вложенные пространства имён), не получают глубину 2 — условие `entity.type === "method" && hasOwningClassInBatch(entity, classNames)` срабатывает только для методов.
- Класс-владелец метода определяется исключительно по именам классов из того же массива `entities`; если метод принадлежит классу из другого файла, `hasOwningClassInBatch` вернёт `false`, и метод будет задокументирован с глубиной 1 и полным именем.

## Как менять и что проверять

- Сортировка по `startOffset`: порядок секций соответствует возрастанию начального смещения сущностей в исходном файле. Конструкция: `[...entities].sort((left, right) => left.range.startOffset - right.range.startOffset)`.
- Заголовок метода класса: для методов, чей класс присутствует в наборе, заголовком становится только имя метода (без префикса класса). Конструкция: `entity.name.slice(lastDot + 1)` внутри условия `entity.type === "method" && hasOwningClassInBatch(entity, classNames)`.
