# decideDocumentationRoles

```ts
decideDocumentationRoles(entities: Record<string, CodeEntity>, metrics: Map<string, EntityMetrics>, cohesion: Map<string, ClassCohesion>, wrappers: WrapperDetection, config: CodeloreConfig): Map<string, EntityDocumentationDecision>
```

## Зачем это нужно

Определяет роль документации для каждой сущности кода на основе метрик, связности классов и обнаружения обёрток.

## Что делает

- Принимает решение о роли документации для каждой сущности, делегируя вычисление роли вспомогательной функции decideEntityRole.
- Не вычисляет метрики, связность или обёртки самостоятельно, а получает их как готовые входные данные.

## На что можно положиться

- Каждая сущность из переданного entities получает ровно одно решение в возвращаемой Map.
- Порядок вставки записей в Map соответствует сортировке сущностей по пути и начальному смещению.
- Для файловой сущности роль определяется вызовом decideFileRole (решение принимается после обработки всех не‑файловых сущностей).
- Функция не изменяет переданные коллекции и не выбрасывает исключений.

## Кто и как использует

Вызывается из populateDocumentationMetadata (внутри buildCodeIndex) после того, как собраны метрики, связность классов и обнаружены обёртки.

## Чего не делает

Решение о роли принимается исключительно на основе метрик, связности классов и обнаружения обёрток; содержимое существующей документации сущности не анализируется и не влияет на выбор роли. Для сущностей без метрик используется fallbackMetrics, который присваивает вес по умолчанию, что может привести к роли one_line для сущностей с неизвестным размером. Роль full_page присваивается только если вес превышает порог weightFull, заданный в конфигурации; при отсутствии порога или его значении по умолчанию сущности с весом ниже порога получают short_page или one_line.

# calculateWeight

## Зачем это нужно

Вычисляет вес сущности на основе её метрик и, при наличии, метрик приватной части якоря, используемый при принятии решений в анализе.

## Что делает

- Принимает два набора метрик и при необходимости объединяет их для расчёта.
- Применяет логарифмическую формулу для получения веса.

## На что можно положиться

Функция не имеет побочных эффектов и является чистой.
