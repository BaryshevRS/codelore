# detectPrivateWrappers

## Зачем это нужно

Определяет, какие приватные методы классов полностью инкапсулированы тонкой публичной обёрткой, для последующего исключения из обязательных блоков документации.

## Что делает

- Не принимает решение о роли сущности — это `decideDocumentationRoles`.
- Не анализирует методы вне классов.
- Не распознаёт вызовы через `call` / `apply` или косвенные обращения.
- Не обрабатывает перегрузки методов.

## На что можно положиться

- Все ключи `anchorByPublicId` — ID публичных методов, все значения `absorbedPrivateById` — ID приватных.
- Приватный метод считается абсорбированным, только если у него ровно одно эффективное использование (`effectiveDirectUsages`) и количество операторов ≥ 3 × количество операторов публичной обёртки.
- Функция никогда не выбрасывает исключения.
- Входные `records` должны содержать узлы `MethodDeclaration` для анализа.

## От чего зависит

- `countStatements` ([`src/analysis/entity-metrics.ts`](entity-metrics.codelore.md)) — подсчёт операторов в теле метода.
- `effectiveDirectUsages` ([`src/analysis/entity-metrics.ts`](entity-metrics.codelore.md)) — подсчёт эффективных прямых использований (исключая файл и класс-владелец).

## Кто и как использует

Вызывается из `populateDocumentationMetadata` в [`src/indexer/code-indexer.ts`](../indexer/code-indexer.codelore.md). Принимает коллекцию записей `records` и карту `entities`. Группирует методы по классам, для каждого публичного метода с 1–2 операторами проверяет, вызывает ли он ровно один приватный метод, который значительно больше (≥3× операторов) и не имеет других использований. Результат `WrapperDetection` передаётся в `decideDocumentationRoles`, где приватные методы с обёрткой помечаются как `absorbed` и исключаются из обязательных блоков документации.

## Чего не делает

- Работает только с методами классов; функции верхнего уровня игнорируются.
- Распознаёт только прямые вызовы `this.method()`; вызовы через `call`, `apply` или рефлексию не отслеживаются.
- Пороговое отношение операторов (3×) жёстко зашито и не настраивается через конфиг.
- Не учитывает перегрузки: если метод имеет несколько сигнатур, анализируется только первая реализация.
