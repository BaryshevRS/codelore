# domain-writer.ts

## Зачем это нужно

Модуль предоставляет набор чистых функций для работы с доменными данными: преобразование объектов в текстовые строки, разбор текста обратно в объекты, а также проверка корректности данных. Все функции не имеют побочных эффектов и не изменяют входные данные.

## Что делает

Модуль выполняет три группы операций: сериализация доменных объектов в текст (для передачи в LLM), десериализация текста обратно в объекты (для обработки ответов LLM), и валидация структуры данных (для проверки целостности перед использованием). Каждая группа реализована отдельными функциями, которые не вызывают друг друга.

## На что можно положиться

Все экспортируемые функции файла работают только с сериализуемыми данными (строки, числа, массивы, объекты без циклических ссылок). Это гарантирует, что результаты можно безопасно передавать через IPC-мост между процессами.

## Чего не делает

Не реализует повторные попытки или резервные стратегии при сбоях LLM.

# buildDomainWriteRequest

```ts
buildDomainWriteRequest(input: BuildDomainWriteRequestInput): ChatCompletionInput
```

## Зачем это нужно

Функция создает структуру запроса для LLM: принимает объект домена и возвращает объект с полем `instruction`, содержащим текстовую инструкцию. Инструкция формируется на основе шаблона, в который подставляется JSON-представление домена.

## Что делает

Функция выполняет две задачи: проверяет, что входной объект является валидным объектом (не null и не массив), и формирует строку инструкции, вставляя JSON-сериализацию домена в шаблон. Если входной объект невалиден, выбрасывается ошибка.

## На что можно положиться

Функция принимает объект домена и возвращает объект запроса. Возвращаемый объект всегда содержит два поля: `domain` (исходный объект) и `instruction` (строка с инструкцией). Если входной объект не является объектом или равен null, функция выбрасывает ошибку.

## Кто и как использует

Принимает доменный объект и возвращает объект запроса, содержащий сериализованный JSON этого объекта.

## Чего не делает

Не проверяет корректность входного доменного объекта.

# parseDomainWriteResponse

```ts
parseDomainWriteResponse(content: string, input: BuildDomainWriteRequestInput, options: { requireCompleteness?: boolean } = {}): FileWriteResult
```

## Зачем это нужно

Функция разбирает ответ LLM: принимает строку, парсит её как JSON, и возвращает объект с полем `domain`, содержащим извлечённый домен. Если разбор не удаётся или поле отсутствует, выбрасывается ошибка.

## Что делает

Функция выполняет две задачи: парсит входную строку как JSON и проверяет, что результат содержит поле `domain`. Если парсинг не удаётся или поле отсутствует, выбрасывается ошибка.

## На что можно положиться

Функция принимает строку ответа LLM и возвращает объект с полем `domain`. Если строка не является валидным JSON, функция выбрасывает ошибку. Если JSON не содержит поле `domain`, функция также выбрасывает ошибку.

## Кто и как использует

Принимает ответ LLM и возвращает доменный объект, извлечённый из JSON-содержимого ответа.

## Чего не делает

Не обрабатывает некорректные JSON-ответы.
