# sha256

```ts
sha256(input: string): string
```

## Зачем это нужно

Хеширует строку алгоритмом SHA-256 и возвращает 64-символьное hex-представление.

## Что делает

- Передаёт вычисление хеша модулю `node:crypto`, последовательно вызывая `createHash`, `update` и `digest`.
- Принимает произвольную строку без предварительной обработки; вызывающая сторона отвечает за то, что именно хешировать.

## На что можно положиться

- Возвращает строку длиной ровно 64 символа в нижнем регистре (hex-кодировка).
- Детерминирован: одинаковый `input` всегда даёт одинаковый результат.
- Не имеет побочных эффектов.
- Не выбрасывает исключений для любого строкового входа.

## Кто и как использует

- В [`src/indexer/code-indexer.ts`](../indexer/code-indexer.codelore.md) — хеширует содержимое файлов и сигнатуры сущностей при построении индекса кода.
- В [`src/markdown/block-facets.ts`](../markdown/block-facets.codelore.md) — вычисляет отпечатки блоков документации для детекции изменений.
- В [`src/llm/file-pipeline.ts`](../llm/file-pipeline.codelore.md) — формирует отпечаток массива `dependencyDocs` для проверки стабильности документации.

## Чего не делает

- Не поддерживает алгоритмы хеширования, отличные от SHA-256.
- Не принимает `Buffer`, `Uint8Array` или другие типы данных — только строку.
- Не реализует HMAC, ключевые хеши или потоковое хеширование.
