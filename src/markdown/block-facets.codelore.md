# computeBlockFingerprint

```ts
computeBlockFingerprint(blockId: BlockId, ownedEntityIds: string[], entities: Record<string, CodeEntity>): string | undefined
```

## Зачем это нужно

Определяет, изменилось ли содержимое блока документации, путём вычисления хеша по релевантным фасетам сущностей.

## Что делает

Вычисляет отпечаток блока, хэшируя конкатенацию значений фасетов всех сущностей, которыми владеет секция, через `hashFacetAcrossEntities`; возвращает `undefined`, если нет владеющих сущностей или если ни одна из них не имеет записи в словаре entities. Определяет набор фасетов, участвующих в хэше, по фиксированному отображению `BLOCK_FACETS[blockId]`. Возвращает `undefined`, если нет владеющих сущностей или ни одна из них не присутствует в entities, иначе — строку отпечатка.

## На что можно положиться

Результат детерминирован при одинаковых входных данных.
Если ownedEntityIds пуст, возвращает undefined.
Если все переданные идентификаторы отсутствуют в entities, возвращает undefined.

## Кто и как использует

Вызывается из [`CodeloreService`](../service/codelore-service.codelore.md#codeloreservice) (`src/service/codelore-service.ts`) при проверке актуальности документации. Функция получает `blockId`, список идентификаторов сущностей и словарь сущностей. Для каждой сущности извлекает фасеты и передаёт их в `hashFacetAcrossEntities`. Результат — строка отпечатка или `undefined`.

## Чего не делает

Не учитывает сущности, отсутствующие в переданном словаре `entities` — они игнорируются без предупреждения. Не поддерживает фасеты, не входящие в `BLOCK_FACETS[blockId]`.

## Как менять и что проверять

When the set of facets that contribute to a block's fingerprint changes (e.g., adding a new facet to `BLOCK_FACETS[blockId]`), the fingerprint value changes for all entities, causing [`staleBlockInfoFor`](../service/stale-detection.codelore.md#staleblockinfofor) to report `drift: "facet_changed"` with the updated `changedFacets` list. The fingerprint is undefined when the block is not allowed for the entity, so callers like [`staleBlockInfoFor`](../service/stale-detection.codelore.md#staleblockinfofor) and `CodeloreService.stampUnwrittenBlocks` must handle the undefined case by skipping the block.

# parseBlockFingerprintValue

## Зачем это нужно

Преобразует строку отпечатка фасетов в объект для последующего сравнения.

## Что делает

Разделяет строку по запятым, извлекает пары фасет=хеш.
Пропускает части без знака `=` или с пустым хешем.

## На что можно положиться

На пустой или невалидной строке возвращает пустой объект.
Результат содержит только ключи, являющиеся валидными AstFacet.
Порядок следования фасетов не сохраняется (объект).

## Кто и как использует

Вызывается из `CodeloreService` ([`src/service/codelore-service.ts`](../service/codelore-service.codelore.md)) при загрузке сохранённого отпечатка из хранилища. Функция принимает строку, разделяет её по запятым, извлекает пары `фасет=хеш` и возвращает объект. Результат передаётся для сравнения с текущим отпечатком.

## Чего не делает

Не проверяет дублирование фасетов в строке — последнее значение перезаписывает предыдущее. Не обрабатывает экранирование символов `=` или `,` в значениях хеша.

## Как менять и что проверять

- Пропуск частей без знака `=` — `if (eq <= 0) { continue; }` не включает такие части в результат. Тест: `block-facets.test.ts`.
- Включение только валидных фасетов — `if (isFacet(facet) && hash.length > 0)` гарантирует, что в результат попадают только известные `AstFacet` с непустым хешем. Тест: `block-facets.test.ts`.

# diffFacetHashes

## Зачем это нужно

Определяет, какие фасеты изменились между сохранённым и текущим отпечатками.

## Что делает

Сравнивает значения каждого фасета в двух объектах. Учитывает только те фасеты, которые присутствуют (не `undefined`) в обоих объектах. Возвращает массив фасетов, значения которых различаются. Не изменяет переданные объекты.

## На что можно положиться

Возвращаемый массив содержит только фасеты из ALL_FACETS, порядок соответствует порядку ALL_FACETS.
Если ни один фасет не изменился, возвращает пустой массив.
Если фасет отсутствует в одном из объектов, он не включается в результат.

## Кто и как использует

Вызывается из `CodeloreService` ([`src/service/codelore-service.ts`](../service/codelore-service.codelore.md)) после загрузки сохранённого отпечатка и вычисления текущего. Функция принимает два объекта, сравнивает значения по каждому фасету и возвращает массив изменившихся фасетов. Результат используется для определения необходимости перегенерации блоков.

## Чего не делает

Не сообщает, какой именно фасет отсутствует — только сравнивает присутствующие. Не поддерживает сравнение вложенных структур — работает только с плоскими строками хешей.

## Как менять и что проверять

- Порядок изменившихся фасетов соответствует `ALL_FACETS` — итерация `for (const facet of ALL_FACETS)` гарантирует фиксированный порядок. Тест: `block-facets.test.ts`.
- Игнорирование фасетов, отсутствующих в одном из объектов — условие `if (left !== undefined && right !== undefined && left !== right)` не включает `undefined` значения в сравнение. Тест: `block-facets.test.ts`.

# translationSourceFingerprint

## Зачем это нужно

Вычисляет фингерпринт канонического тела блока, чтобы определить, устарел ли перевод.

## Что делает

- Удаляет начальные и завершающие пробелы из переданного тела.
- Вычисляет SHA-256 хеш обрезанной строки.
- Возвращает хеш в виде строки.

## На что можно положиться

Функция детерминирована: одинаковое тело (с точностью до завершающих пробелов) всегда даёт одинаковый хеш. Завершающие пробелы игнорируются благодаря обрезке перед хешированием.

## От чего зависит

Зависит от [`sha256`](../utils/hash.codelore.md#sha256) из `src/utils/hash.ts`.

## Кто и как использует

Вызывается в двух сценариях. 1) В `renderDoc.ts` функция `blockBody` сравнивает `translation.sourceFingerprint` с результатом `translationSourceFingerprint(block.body)`, чтобы решить, показывать ли перевод или заглушку. 2) В `CodeloreService.translateDoc` результат `translationSourceFingerprint(block.body)` сохраняется как `sourceFingerprint` в объекте перевода, фиксируя каноническое тело на момент перевода.

## Чего не делает

Функция не проверяет, что переданное тело является валидным Markdown или что оно не пустое; она хеширует любую строку, включая пустую.
