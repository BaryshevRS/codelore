# computeBlockFingerprint

```ts
computeBlockFingerprint(blockId: BlockId, ownedEntityIds: string[], entities: Record<string, CodeEntity>): string | undefined
```

## Зачем это нужно

Определяет, изменилось ли содержимое блока документации, путём вычисления хеша по релевантным фасетам сущностей.

## Что делает

Вычисляет отпечаток блока, хэшируя конкатенацию значений фасетов всех сущностей, которыми владеет секция, через `hashFacetAcrossEntities`; возвращает `undefined`, если нет владеющих сущностей или если ни одна из них не имеет записи в словаре entities. Определяет набор фасетов, участвующих в хэше, по фиксированному отображению `BLOCK_FACETS[blockId]`. Возвращает `undefined`, если нет владеющих сущностей или ни одна из них не присутствует в entities, иначе — строку отпечатка.

## На что можно положиться

Результат детерминирован при одинаковых входных данных.
Если ownedEntityIds пуст, возвращает undefined.
Если все переданные идентификаторы отсутствуют в entities, возвращает undefined.

## Кто и как использует

Вызывается из [`CodeloreService`](../service/codelore-service.codelore.md#codeloreservice) (`src/service/codelore-service.ts`) при проверке актуальности документации. Функция получает `blockId`, список идентификаторов сущностей и словарь сущностей. Для каждой сущности извлекает фасеты и передаёт их в `hashFacetAcrossEntities`. Результат — строка отпечатка или `undefined`.

## Чего не делает

Не учитывает сущности, отсутствующие в переданном словаре `entities` — они игнорируются без предупреждения. Не поддерживает фасеты, не входящие в `BLOCK_FACETS[blockId]`.

## Как менять и что проверять

When the set of facets that contribute to a block's fingerprint changes (e.g., adding a new facet to `BLOCK_FACETS[blockId]`), the fingerprint value changes for all entities, causing [`staleBlockInfoFor`](../service/stale-detection.codelore.md#staleblockinfofor) to report `drift: "facet_changed"` with the updated `changedFacets` list. The fingerprint is undefined when the block is not allowed for the entity, so callers like [`staleBlockInfoFor`](../service/stale-detection.codelore.md#staleblockinfofor) and [`CodeloreService.stampUnwrittenBlocks`](../service/codelore-service.codelore.md#codeloreservicestampunwrittenblocks) must handle the undefined case by skipping the block.

# parseBlockFingerprintValue

```ts
parseBlockFingerprintValue(value: string): Partial<Record<AstFacet, string>>
```

## Зачем это нужно

Преобразует строку отпечатка фасетов в объект для последующего сравнения.

## Что делает

- Делит строку по запятым и в каждой части находит первое вхождение `=`; фасет берёт из текста до знака, хеш — из текста после, у обоих обрезает концевые пробелы, сам `=` в хеше дальше не интерпретируется.
- Пропускает часть целиком, если в ней нет `=` (или `=` стоит на первой позиции), если хеш после обрезки пуст или если фасет не признан валидным: «признан» означает, что локальный `isFacet` нашёл имя в `ALL_FACETS` — `signature`, `body`, `deps`, `usage`, `placement`.

## На что можно положиться

На пустой или невалидной строке возвращает пустой объект.
Результат содержит только ключи, являющиеся валидными AstFacet.
Порядок следования фасетов не сохраняется (объект).

## Кто и как использует

Вызывается из `CodeloreService` ([`src/service/codelore-service.ts`](../service/codelore-service.codelore.md#codelore-servicets)) при загрузке сохранённого отпечатка из хранилища. Функция принимает строку, разделяет её по запятым, извлекает пары `фасет=хеш` и возвращает объект. Результат передаётся для сравнения с текущим отпечатком.

## Чего не делает

Не проверяет дублирование фасетов в строке — последнее значение перезаписывает предыдущее. Не обрабатывает экранирование символов `=` или `,` в значениях хеша.

## Как менять и что проверять

- Части без `=` или с `=` на первой позиции не попадают в результат — `if (eq <= 0) { continue; }` пропускает их ещё до чтения имени и хеша.
- В результат входят только известные `AstFacet` с непустым хешем — `if (isFacet(facet) && hash.length > 0)`; валидность имени решает локальный `isFacet`, сверяющий его с `ALL_FACETS`.
- Пробелы вокруг имени и хеша обрезаются — `.trim()` в `part.slice(0, eq).trim()` и `part.slice(eq + 1).trim()`, иначе фрагмент с пробелом после запятой не совпал бы с именем фасета.

# diffFacetHashes

```ts
diffFacetHashes(stored: Partial<Record<AstFacet, string>>, current: Partial<Record<AstFacet, string>>): Facet[]
```

## Зачем это нужно

Определяет, какие фасеты изменились между сохранённым и текущим отпечатками.

## Что делает

- Для каждого фасета из `ALL_FACETS` достаёт хеши из обоих объектов и помечает его изменившимся только тогда, когда значения строго не равны (`left !== right`); содержимое хешей не интерпретируется.
- Список сравниваемых фасетов берётся только из константы `ALL_FACET`, а не из ключей входных объектов: появившаяся в одном из объектов новая пара «фасет=хеш» не включает фасет в проверку, пока его нет в `ALL_FACETS`.
- Входные объекты не модифицирует: читает их только по ключам и собирает результат в массив.

## На что можно положиться

Возвращаемый массив содержит только фасеты из ALL_FACETS, порядок соответствует порядку ALL_FACETS.
Если ни один фасет не изменился, возвращает пустой массив.
Если фасет отсутствует в одном из объектов, он не включается в результат.

## Кто и как использует

Вызывается из `CodeloreService` ([`src/service/codelore-service.ts`](../service/codelore-service.codelore.md#codelore-servicets)) после загрузки сохранённого отпечатка и вычисления текущего. Функция принимает два объекта, сравнивает значения по каждому фасету и возвращает массив изменившихся фасетов. Результат используется для определения необходимости перегенерации блоков.

## Чего не делает

Не сообщает, какой именно фасет отсутствует — только сравнивает присутствующие. Не поддерживает сравнение вложенных структур — работает только с плоскими строками хешей.

## Как менять и что проверять

- Порядок результата зафиксирован списком `ALL_FACETS` — цикл `for (const facet of ALL_FACETS)` перебирает фасеты в неизменном порядке, а не по ключам входных объектов.
- Сравниваются только фасеты, присутствующие в обоих отпечатках — условие `if (left !== undefined && right !== undefined && left !== right)` исключает `undefined` и фасет, отсутствующий хотя бы в одном объекте, из результата.
- Сравнение строго по значению — `left !== right` помечает фасет изменившимся только при неравных строках; одинаковые хеши не дают записи в массиве.

# translationSourceFingerprint

## Зачем это нужно

Вычисляет фингерпринт канонического тела блока, чтобы определить, устарел ли перевод.

## Что делает

- Удаляет начальные и завершающие пробелы из переданного тела.
- Вычисляет SHA-256 хеш обрезанной строки.
- Возвращает хеш в виде строки.

## На что можно положиться

Функция детерминирована: одинаковое тело (с точностью до завершающих пробелов) всегда даёт одинаковый хеш. Завершающие пробелы игнорируются благодаря обрезке перед хешированием.

## От чего зависит

Зависит от [`sha256`](../utils/hash.codelore.md#sha256) из `src/utils/hash.ts`.

## Кто и как использует

Вызывается в двух сценариях. 1) В `renderDoc.ts` функция `blockBody` сравнивает `translation.sourceFingerprint` с результатом `translationSourceFingerprint(block.body)`, чтобы решить, показывать ли перевод или заглушку. 2) В `CodeloreService.translateDoc` результат `translationSourceFingerprint(block.body)` сохраняется как `sourceFingerprint` в объекте перевода, фиксируя каноническое тело на момент перевода.

## Чего не делает

Функция не проверяет, что переданное тело является валидным Markdown или что оно не пустое; она хеширует любую строку, включая пустую.
