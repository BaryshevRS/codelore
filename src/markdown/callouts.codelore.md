# staleCalloutText

## Зачем это нужно

Обеспечивает единообразное отображение уведомлений об устаревших блоках в виде маркдаун-цитаты, используя локализованные шаблоны из localeBundle.

## Что делает

- Разрешает локализованную фразу причины: если group.reason присутствует и есть в bundle.reasons, использует её; иначе — исходный ключ.
- Заполняет шаблон bundle.callouts.stale подставляя значения reason (с запятой и пробелом), since и headings.
- Возвращает строку с префиксом "> " и заполненным шаблоном.

## От чего зависит

Использует localeBundle из [src/markdown/locales.ts](locales.codelore.md) для получения локализованного набора строк callouts.

## Кто и как использует

Вызывается из renderSection ([src/markdown/render-doc.ts](render-doc.codelore.md)) для каждого сгруппированного набора устаревших блоков на этапе рендеринга секции. Функция renderSection собирает все блоки, помеченные staleSince, группирует их по совпадению reason и since, и для каждой группы вызывает staleCalloutText, передавая язык и объект StaleGroup. Результат вставляется в массив lines сразу после заголовка секции, формируя сводный баннер устаревания.

# translationPendingCalloutText

## Зачем это нужно

Создаёт текстовую цитату, сообщающую, что перевод данного блока ещё не готов, для вставки в документ вместо отсутствующего перевода.

## Что делает

- Извлекает локализованный текст из localeBundle(language).callouts.translationPending.
- Возвращает строку с префиксом "> " и этим текстом.

## Кто и как использует

Вызывается из blockBody ([src/markdown/render-doc.ts](render-doc.codelore.md)) в момент, когда для блока запрошен перевод на указанный язык, но перевод либо отсутствует в store, либо его sourceFingerprint не соответствует текущему каноническому телу блока. blockBody сначала проверяет наличие translationLanguage и при отсутствии/несовпадении fingerprint вызывает translationPendingCalloutText и добавляет результат в lines, возвращая undefined как тело блока.
