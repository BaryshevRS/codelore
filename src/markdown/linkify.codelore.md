# linkify.ts

## Зачем это нужно

Преобразует ссылки вида file: в абсолютные пути, чтобы они корректно работали в сгенерированной документации, и оставляет все остальные ссылки без изменений.

## Что делает

- Определяет, является ли ссылка ссылкой file: по префиксу.
- Извлекает путь из URL и преобразует его в абсолютный путь, если он относительный.
- Возвращает исходную ссылку без изменений для всех не-file: ссылок.

## На что можно положиться

Функция обрабатывает только ссылки, начинающиеся с префикса file:; все остальные ссылки (например, http:, https:, mailto:) возвращает без изменений. Для ссылок file: она извлекает путь из URL и преобразует его в абсолютный путь, если он относительный. Если путь не может быть преобразован (например, из-за недопустимых символов), функция возвращает исходную ссылку без изменений.

## Чего не делает

Функция не обрабатывает ссылки, в которых отсутствует символ '#', так как она ищет якорь только после этого разделителя. Она также не проверяет, существует ли целевой файл на диске, и не разрешает относительные пути — предполагается, что docPath уже корректен.

# buildEntityLinkMap

```ts
buildEntityLinkMap(states: Iterable<DocState>): Map<string, LinkTarget>
```

## Зачем это нужно

Создаёт карту ссылок на сущности, сопоставляя имя сущности с её ссылкой, чтобы впоследствии по имени можно было найти ссылку.

## Что делает

- Перебирает все сущности.
- Для каждой сущности с ссылкой добавляет запись в карту.
- Пропускает сущности без ссылки.

## На что можно положиться

Функция строит карту ссылок для всех сущностей, пропуская те, у которых нет ссылки. Для каждой сущности с ссылкой она добавляет запись в карту, используя имя сущности в качестве ключа.

## От чего зависит

Функция не использует внешние модули; она опирается только на локальный тип LinkTarget, определённый в этом же файле.

## Кто и как использует

Функция вызывается из linkify для каждой ссылки, найденной в документе, и добавляет её в общую карту ссылок. Это происходит в процессе обработки всех документов, когда linkify собирает все ссылки для последующего разрешения.

## Чего не делает

Функция не проверяет, существует ли уже запись с таким ключом в карте, и при повторном вызове с тем же ключом перезаписывает предыдущее значение. Она также не проверяет, что docPath является валидным путём.

## Как менять и что проверять

- Функция группирует ссылки по имени сущности, используя `entityName` как ключ карты, что гарантирует уникальность записей для каждой сущности.\n- Если anchor задан, он используется как ключ внутри группы, иначе ключом становится пустая строка; это поведение закреплено в выражении `anchor ?? ""`.

# addDocToLinkMap

```ts
addDocToLinkMap(links: Map<string, LinkTarget>, state: DocState): void
```

## Зачем это нужно

Регистрирует документ в карте ссылок, сопоставляя ключ с путём документа, чтобы впоследствии по ключу можно было найти путь.

## Что делает

- Проверяет, существует ли ключ в карте.
- Если ключа нет, добавляет запись с путём документа.
- Если ключ уже есть, ничего не делает.

## Чего не делает

Функция не проверяет, существует ли уже запись с таким ключом в карте, и при повторном вызове с тем же ключом перезаписывает предыдущее значение. Она также не проверяет, что docPath является валидным путём.

## Как менять и что проверять

- Функция добавляет запись в карту ссылок только при непустом docPath, что гарантирует отсутствие пустых ключей; это условие проверяется оператором `if (docPath)`.\n- Если anchor задан, он используется как ключ записи, иначе ключом становится пустая строка; это поведение закреплено в выражении `anchor ?? ""`.
